# L.E.M.A. 2026

Sitio web oficial de **L.E.M.A. – Encuentro Académico de Matemáticas 2026**, organizado por el Grupo Estudiantil de Matemática (GEM) de la Universidad Nacional de Ingeniería.

## Publicación con GitHub Pages

1. En el repositorio, entra a **Settings**.
2. Ve a **Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama **main** y la carpeta **/(root)**.
5. Pulsa **Save**.

GitHub generará una dirección similar a:

`https://algebra-lover-n6.github.io/LEMA/`

Cada vez que se actualicen `index.html`, `styles.css` o `script.js` en la rama `main`, GitHub Pages publicará los cambios automáticamente.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseño responsivo.
- `script.js`: menú, pestañas del horario, animaciones y cuenta regresiva.
